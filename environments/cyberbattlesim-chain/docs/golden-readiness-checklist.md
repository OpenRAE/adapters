# CyberBattleSim chain golden readiness checklist

This operator checklist records the final manual review required before the
pack may move beyond its evidence-backed status. It is not participant content.

## Golden Definition Of Done

- [ ] `raes-pack-validate --pack .` exits zero.
- [ ] `raes-pack-release check --pack .` reports the pack releasable.
- [ ] The derived content digest matches `pack.content-manifest.json` and the
      checksum of the immutable GitHub Release asset.
- [ ] The exact qualified CyberBattleSim source commit and dependency artifacts
      pass the adapter's pre-import source admission.
- [ ] The installed command validates the pack, runs the selected
      `CredentialCacheExploiter` short episode and declared seeded batch through
      RAES admission, and seals a portable inventory with verified cleanup.
- [ ] Pack build, automated rehearsal, this walkthrough, and the recorded native
      run bind the same scenario digest, task/spec, participant configuration,
      episode controls, seeds, objective, and evaluator.
- [ ] Participant/public release views contain no operator, evaluator, source,
      native observation, action coordinate, credential, reward vector, hidden
      state, raw log, path, environment, or traceback sentinel.
- [ ] Provenance covers every upstream/generated source, exclusion,
      redistribution decision, license/notice obligation, and safety review.
- [ ] No result claims deterministic replay, state/outcome equivalence,
      benchmark comparability, or scientific validity.

## Final Manual Participant Walkthrough Protocol

- [ ] Read `docs/concepts.md` and `docs/attack-path.md` from the participant view.
- [ ] Confirm the red selection binds `participant.behavior.red` to the exact
      manifest and realized configuration digests.
- [ ] Confirm every native proposal exposes only its semantic action contract
      before a source transition and that the evaluator remains a separate view.
- [ ] Confirm the scenario objective and experiment controls agree with the
      canonical installed mirrors and the recorded native rehearsal.
