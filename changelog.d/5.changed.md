Complete the hard cutover to RAES as the repository's sole identity and semantic
authority. The root distribution is now `raes-adapters`, the CybORG adapter is
`raes-adapter-cyborg` importing `raes_adapter_cyborg`, and `sim_adapter_base`
consumes the published `raes==2.0.0` contracts from PyPI through its own
lockfile. ADR-002 supersedes ADR-000 and ADR-001. A fail-closed identity gate
(`tools/check_identity_policy.py`) scans tracked path names and bytes, built
wheels and sdists, and installed distribution metadata with one matcher, and the
`distributions` nox session proves each package clean-installs outside the
checkout with the retired import path gone. This release is intentionally
breaking: there are no aliases, shims, or dual-name compatibility paths.
